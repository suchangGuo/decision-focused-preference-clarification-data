# Data Availability Statement

The materials supporting the computational experiments, including test
instances, parameter settings, random seeds, raw solver logs, processed
results, and source data for the reported tables and figures, are available in
the accompanying repository at
`https://github.com/suchangGuo/decision-focused-preference-clarification-data`.
The repository also provides the experimental protocol, computational
environment, frozen configuration files, and data-processing scripts used for
the reported analyses and figures.
