# Data Availability Statement

The computational materials supporting this study are available at
https://github.com/suchangGuo/decision-focused-preference-clarification-data.
The repository contains the frozen test instances, parameter-calibration
records, experimental configurations and random seeds, raw and processed
numerical results, and source data for the reported computational tables and
data figures. It also provides the experimental protocol, computational
environment, and data-processing and figure-generation scripts used in the
analyses.
